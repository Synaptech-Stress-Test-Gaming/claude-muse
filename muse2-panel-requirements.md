# Muse 2 Control Panel: Requirements

Status: information only. Nothing is planned or built yet.

## Goal
Get raw brainwave data from a Muse 2 headband onto Julian's laptop for testing. This is a raw data test only. No game engine is involved. No consumer-style app.

## Starting point
- BlueMuse (free, streams Muse 2 raw data to Windows): https://github.com/kowalej/BlueMuse

## Laptop
- 14 inch, non-touchscreen
- Trackpad only
- Buttons must be large, with generous spacing so they are easy to hit with a trackpad

## Look and feel
- Art deco aesthetic
- Color scheme: navy and silver

## What the panel shows
- Connect and disconnect status
- Signal quality
- Battery level
- Live brainwave lines

## Buttons
- Connect
- Disconnect
- Start Recording
- Stop Recording

## Wave controls
- The Muse 2 wave types: delta, theta, alpha, beta, gamma
- Each wave type gets its own large slider to turn it down
- Each wave type gets its own mute button to switch it off completely

## Connection behavior
- Connects automatically as soon as the Muse 2 turns on

## Saving
- No saving. Nothing is stored for later or replayed.

## Out of scope
- Game engine integration (not applicable for this test)
- Replay of past sessions

## Open question
- Start Recording and Stop Recording are on the button list, but saving is off. Decide what these buttons should do (for example, mark a live session on screen only), or remove them.
